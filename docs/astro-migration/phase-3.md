## 公開設定

`vercel.json` にAstroのフレームワーク、frozen/strictのインストール、`pnpm build`、出力先 `dist` を指定した。SSRアダプターは使わない。

- `cleanUrls: true`、`trailingSlash: false` で既存の拡張子なしURLを維持する設定。
- 外部metagenへのrewriteを削除。旧 `/sitemap.xml` は `/sitemap-index.xml` へ恒久転送する設定。
- `VERCEL_ENV=production` のみ検索登録・GTMを有効化。Previewと開発ではGTMを出力せず、noindexとrobotsで検索登録を抑制。
- GTMは `GTM_ID` を優先し、既存の `NEXT_PUBLIC_GTAGMGR_ID` も受け付ける。`GTM-` 接頭辞の有無を吸収する。本番でIDが未設定・不正ならビルドを失敗させる。
- ローカルの本番出力確認用に `SITE_ENV=production` を利用できる。`VERCEL_ENV` があればそちらを優先し、Previewで本番設定へ切り替わらない。

GTMはGoogleの標準headスクリプトとbody冒頭のnoscriptを出力する。計測先への実送信とVercel上のHTTP転送は工程4で確認する。
